# Day 002 — Beginner Problem Solving

Focus: loops, conditions, numbers, strings, arrays, and simple functions.

1. Print numbers from 1 to N.
2. Print numbers from N to 1.
3. Print even numbers in a range.
4. Print odd numbers in a range.
5. Sum numbers from 1 to N.
6. Find factorial of N.
7. Generate the first N Fibonacci numbers.
8. Check whether a number is prime.
9. Print all primes in a range.
10. Find GCD using Euclid's algorithm.
11. Find LCM of two numbers.
12. Reverse a number without converting it to a string.
13. Count digits in a number.
14. Find the sum of digits.
15. Check whether a number is a palindrome.
16. Check whether a number is an Armstrong number.
17. Check whether a number is a perfect number.
18. Find the largest of three numbers without Math.max.
19. Swap two values.
20. Convert Celsius to Fahrenheit and vice versa.
21. Count vowels in a string.
22. Count words in a sentence.
23. Reverse a string with a loop.
24. Check whether a string is a palindrome.
25. Find the first repeated character.
26. Find the first non-repeated character.
27. Count each character in a string.
28. Remove duplicate characters.
29. Find the longest word in a sentence.
30. Capitalize every word without map.
31. Find array sum without reduce.
32. Find minimum and maximum without built-ins.
33. Count positive, negative, zero, even, and odd values.
34. Copy an array without sharing its top-level reference.
35. Reverse an array without reverse.
36. Remove duplicates from an array.
37. Find the second-largest distinct value.
38. Find the missing number from 1..N.
39. Check whether an array is sorted.
40. Merge two arrays without duplicates.
41. Find common values between two arrays.
42. Move zeroes to the end.
43. Rotate an array right by one position.
44. Split an array into chunks.
45. Flatten one level of nested arrays without flat.
46. Create a frequency map for array values.
47. Find all pairs whose sum equals a target.
48. Build a multiplication table.
49. Create a simple calculator.
50. Validate a password using length, digit, uppercase, and special-character rules.

For every problem: include examples, edge cases, time complexity, space complexity, and mutation behavior.
