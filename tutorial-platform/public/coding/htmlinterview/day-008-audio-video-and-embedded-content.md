# Day 008 — Media, Responsive Images, and Frames

Matches Tutorial Day 8 (Audio Video and Embedded Content).

## Basic

1. Add a video with controls, dimensions, poster, and fallback text/link.
2. Add two `<source>` options with accurate MIME types.
3. Add an English caption track to a video.
4. Create a responsive `<picture>` with a working `img` fallback and meaningful alt text.
5. Embed a map or video in an iframe with a specific title and lazy loading.

## Concept Questions

6. What does `preload="metadata"` request?
7. How do captions differ from a transcript?
8. Why should autoplay not be the default?
9. What should be checked before allowing iframe permissions?

## Challenge

10. Create a media gallery with one video, one audio clip, one responsive image, and one external iframe. Give every item a text equivalent or a direct fallback link.

## Notes

- Replace sample file paths with real media before testing playback.
- Browser support depends on both container format and codec.
