# Day 46 Interview Questions — Built-in Pipes

## Interview Goal
Explain **Built-in Pipes**, implement the relevant Angular pattern, discuss trade-offs, and apply it to a realistic JobHub scenario.

## Interview Questions

### 1. What problem do built-in pipes solve?
**Expected Answer:** They format values for display directly in the template instead of formatting them manually in component code.

### 2. Name four built-in Angular pipes.
**Expected Answer:** DatePipe, CurrencyPipe, DecimalPipe, and UpperCasePipe (or PercentPipe, TitleCasePipe, JsonPipe).

### 3. How do you chain multiple pipes in a template?
**Expected Answer:** Apply pipes one after another with the pipe operator, for example `{{ job.title | uppercase | slice:0:30 }}`.

### 4. What question should a pipe answer, and what question should it not answer?
**Expected Answer:** A pipe should answer "how should this value appear?" and should not answer "how should the application change its business state?"

### 5. Why use CurrencyPipe/DatePipe instead of manually formatting values in the component class?
**Expected Answer:** Built-in pipes are tested, locale-aware, and keep formatting declarative and reusable in the template.

### 6. What is a potential downside of chaining too many pipes in one template expression?
**Expected Answer:** It can make the template harder to read; chaining should stop once the expression is no longer easy to understand.

### 7. What is a common mistake when using pipes for formatting?
**Expected Answer:** Reimplementing formatting logic manually in the component instead of using an existing built-in pipe.

### 8. JobHub scenario: a Job Details screen must show salary as currency, posted date, and job title in title case. Which built-in pipes fit each?
**Expected Answer:** CurrencyPipe for the salary, DatePipe for the posted date, and TitleCasePipe for the job title.

## Interviewer Follow-Ups
- Why did you choose this approach?
- What alternative Angular approach could solve the same problem?
- What happens when the data changes?
- How would you test this behavior?
- What would you change for a large enterprise application?

## Common Interview Trap
Do not memorize syntax alone. Explain why the pattern fits the problem and which layer owns the responsibility.
