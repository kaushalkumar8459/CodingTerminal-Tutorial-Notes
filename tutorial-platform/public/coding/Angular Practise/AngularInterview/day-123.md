# Day 123 — Route Guards for Authentication

## Interview Goal
Use Angular route guards to control navigation while understanding their security limitations.

## Level 1 — Basic Questions
1. What is a route guard?
2. Why would JobHub need an authentication guard?
3. What should a guard return?
4. What is a redirect from a guard?
5. Can a route guard secure a backend API?

## Level 2 — Understanding
1. Compare authentication guards with authorization guards.
2. Why should guards depend on application authentication state?
3. What should happen when authentication state is still loading?
4. Why should a guard return a navigation result rather than relying on unnecessary imperative navigation?
5. Why should backend APIs still enforce authentication?

## Level 3 — Practical
1. Create a functional authentication guard.
2. Protect the recruiter area.
3. Preserve the requested URL for post-login navigation.
4. Handle an unknown authentication state.
5. Test allowed and blocked navigation.

## JobHub Scenarios
1. An anonymous user opens /recruiter/jobs/new. What should happen?
2. A logged-in candidate opens an admin route. Which concern does an auth guard solve, and which does it not?
3. Authentication state loads asynchronously during navigation. How should the guard coordinate with it?
4. A user logs in after being redirected from a deep link. How should the original URL be restored?

## Interviewer Follow-Ups
- Functional guard versus class-based guard?
- Can guards make HTTP calls?
- What happens if multiple guards protect one route?
- How would you test a guard with RouterTestingHarness?

## Coding Question
Implement a functional auth guard that redirects anonymous users to /login while preserving the intended destination.

## Debugging Scenario
The guard always redirects because it reads the authentication signal before session bootstrap completes. Identify the state-model problem.

## Common Interview Traps
- Treating guards as API security.
- Imperatively navigating inside guards unnecessarily.
- Ignoring asynchronous bootstrap.
- Forgetting deep-link restoration.

## Project Connection — JobHub
Authentication guards protect candidate, recruiter, and admin navigation boundaries.

## Quick Revision
Guards improve navigation control and UX; backend authorization remains the actual security boundary.

## Interview Readiness
You are ready when you can implement a guard and explain exactly what it cannot secure.
