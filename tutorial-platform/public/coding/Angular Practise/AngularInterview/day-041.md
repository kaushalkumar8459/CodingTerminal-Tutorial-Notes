# Day 41 Interview Questions — Why Directives and Pipes?

## Interview Goal
Explain **Why Directives and Pipes?**, implement the relevant Angular pattern, discuss trade-offs, and apply it to a realistic JobHub scenario.

## Interview Questions

### 1. What is a directive in Angular?
**Expected Answer:** A directive adds reusable behavior to an existing host element or component without owning a new piece of UI structure.

### 2. What is the difference between a component and a directive?
**Expected Answer:** A component owns its own template and UI structure; a directive attaches to an existing host element and enhances it.

### 3. What is a pipe used for?
**Expected Answer:** A pipe transforms a value for display in a template, such as formatting a date or currency amount.

### 4. Why should display formatting live in a pipe rather than inside a component method?
**Expected Answer:** Keeping formatting in a pipe keeps templates declarative and reusable, and separates presentation from component logic.

### 5. Why not just create a component for every reusable behavior?
**Expected Answer:** Creating a component for simple shared behavior can be unnecessary overhead; a directive can add behavior without owning surrounding markup.

### 6. Give an example of something that is naturally a directive rather than a component.
**Expected Answer:** A reusable highlight-on-hover behavior applied to buttons, cards, or inputs.

### 7. Give an example of something that is naturally a pipe.
**Expected Answer:** Formatting a salary number as currency or a date as a readable string.

### 8. What is a common mistake when deciding between a component, directive, or pipe?
**Expected Answer:** Putting business calculations inside presentation pipes, or using a pipe to mutate application state.

### 9. JobHub scenario: JobHub needs a reusable hover-highlight behavior on job cards and a way to format salary numbers for display. Which abstractions fit each requirement?
**Expected Answer:** The hover-highlight behavior fits a directive because it enhances existing host elements; the salary formatting fits a pipe because it is a display transformation.

## Interviewer Follow-Ups
- Why did you choose this approach?
- What alternative Angular approach could solve the same problem?
- What happens when the data changes?
- How would you test this behavior?
- What would you change for a large enterprise application?

Do not memorize syntax alone. Explain why the pattern fits the problem and which layer owns the responsibility.
