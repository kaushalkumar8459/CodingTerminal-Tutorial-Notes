# Day 47 Interview Questions — Custom Pipes

## Interview Goal
Explain **Custom Pipes**, implement the relevant Angular pattern, discuss trade-offs, and apply it to a realistic JobHub scenario.

## Interview Questions

### 1. When should you create a custom pipe instead of using a built-in one?
**Expected Answer:** When the required display transformation is not covered by a built-in pipe, such as a domain-specific relative-time or label format.

### 2. What is a pure pipe?
**Expected Answer:** A pipe that is recalculated only when Angular detects that its input reference or primitive value has changed.

### 3. When is an impure pipe justified, and what is the risk of using one?
**Expected Answer:** It is justified only for rare cases needing recalculation on every change-detection cycle; the risk is unnecessary recalculation and performance cost.

### 4. What should a custom pipe never do?
**Expected Answer:** Make API calls, mutate external state, or produce non-deterministic output for the same input.

### 5. How would you implement a relativeDays pipe that shows "today", "1 day ago", "5 days ago"?
**Expected Answer:** Implement a `transform(days: number)` method that returns "today" for 0, "1 day ago" for 1, and `${days} days ago` otherwise.

### 6. Why keep a custom pipe's transform() method deterministic?
**Expected Answer:** Deterministic output for the same input lets Angular safely treat the pipe as pure and makes behavior predictable and testable.

### 7. What is a common mistake when writing custom pipes?
**Expected Answer:** Putting API calls or state mutation inside a pipe instead of keeping it a pure presentation transformation.

### 8. JobHub scenario: JobHub wants to show "Posted 3 days ago" from a postedDaysAgo number. Where should the formatting rule live and why?
**Expected Answer:** In a custom relativeDays pipe, so the presentation rule stays out of the template and out of business components and can be reused anywhere it is needed.

## Interviewer Follow-Ups
- Why did you choose this approach?
- What alternative Angular approach could solve the same problem?
- What happens when the data changes?
- How would you test this behavior?
- What would you change for a large enterprise application?

## Common Interview Trap
Do not memorize syntax alone. Explain why the pattern fits the problem and which layer owns the responsibility.
