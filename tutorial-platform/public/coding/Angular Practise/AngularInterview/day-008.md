# Day 8 — Angular Templates: Interview Questions

## Topic

**Angular template syntax, interpolation, property binding, event binding overview**

## Interview Goal

Understand how Angular templates connect UI with component state.

---

## Interview Questions

### Q1. What is an Angular template?

**Expected Answer:**
It is the component's view definition using HTML plus Angular template syntax.

### Q2. What types of binding are commonly used in Angular templates?

**Expected Answer:**
Interpolation, property binding, event binding and two-way binding are the core binding forms introduced across the early lessons.

### Q3. Why does Angular use template syntax?

**Expected Answer:**
It provides a declarative way to connect component state and user interaction with the UI.

### Q4. Can you put arbitrary JavaScript statements in a template expression?

**Expected Answer:**
No. Template expressions have Angular-specific rules and should remain focused on presentation.

### Q5. What is the purpose of interpolation?

**Expected Answer:**
It evaluates an expression and renders its result into text in the template.

### Q6. What is the purpose of property binding?

**Expected Answer:**
It assigns a value to a DOM or component property from template state.

### Q7. Scenario: You need to disable a button based on component state. Which binding is appropriate?

**Expected Answer:**
Property binding such as `[disabled]` is appropriate.

### Q8. Practical: Build a template that displays a user's name, image and account status using Angular bindings.

**Expected Answer:**
The learner should identify which binding type is used for each UI requirement.
