# Day 5 — Component Template and Styles: Interview Questions

## Topic

**Angular templates, template expressions, component styles**

## Interview Goal

Build visible component UI using HTML, bindings and component styles.

---

## Interview Questions

### Q1. What is an Angular template?

**Expected Answer:**
A template is the HTML-based view associated with a component and can contain Angular template syntax.

### Q2. How is an Angular template different from plain HTML?

**Expected Answer:**
It can use Angular expressions and binding syntax to connect the view with component data and behavior.

### Q3. Where can component styles be defined?

**Expected Answer:**
They can be defined inline or in referenced stylesheet files through component metadata.

### Q4. Are component styles automatically global?

**Expected Answer:**
Normally component styles are scoped to the component through Angular's component styling mechanism.

### Q5. Why should presentation logic stay in the template while complex business logic stays elsewhere?

**Expected Answer:**
Keeping templates focused on presentation improves readability, testability and separation of concerns.

### Q6. What is a template expression?

**Expected Answer:**
It is an expression evaluated in the template context to produce a value for the UI.

### Q7. Scenario: A template contains a very expensive method call that runs frequently. What is the concern?

**Expected Answer:**
It can add unnecessary computation during rendering; state or derived values should be structured appropriately.

### Q8. Practical: Build a profile card with a title, description, image and component stylesheet.

**Expected Answer:**
The learner should create a reusable-looking UI and explain which parts belong to the template and component styles.
