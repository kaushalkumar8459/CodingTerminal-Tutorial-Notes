# Day 026 — Problem-Solving Challenge (Mixed, No Hints)

Matches Tutorial Day 26 (String Problem Solving Practice). 20 mixed problems combining
conditions, loops, functions, numbers, and strings — deliberately without solution hints,
to build independent problem-solving confidence. No limit on extending this further.

1. Check if a number is a multiple of both 4 and 6.
2. Print all numbers between 1 and 50 that are NOT divisible by 3.
3. Given a sentence, count how many words start with a vowel.
4. Given an array of numbers, count how many are negative.
5. Write a function that returns the second largest number in a fixed list (no sorting allowed).
6. Given a string, check whether it contains only digits.
7. Given a number, print its digits in reverse order, one per line.
8. Given a sentence, find the shortest word.
9. Write a function that checks if a given year is a leap year AND divisible by 4 but not 100 (unless also divisible by 400).
10. Given an array of numbers, find how many are prime.
11. Given a string, remove all vowels and return the result.
12. Given a number, check whether it's a "happy number" (look up the rule if unfamiliar, then implement it).
13. Given two strings, check if one is a rotation of the other (e.g. "abcd" and "cdab").
14. Given a sentence, capitalize only the first letter of the whole sentence (not every word).
15. Given an array of numbers, find the sum of only the even-indexed elements.
16. Write a function that prints "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for both, from 1 to 50 (the classic FizzBuzz problem).
17. Given a string, check if it has balanced parentheses (equal opening and closing).
18. Given a number, determine how many trailing zeros its factorial would have (think about factors of 10).
19. Given a sentence, find the most frequently occurring word.
20. Given an array of numbers, rearrange it so all even numbers come before all odd numbers (order within each group doesn't matter).

## Notes

- These are intentionally left without hints — struggle with each one for a while before
  looking anything up. That struggle is where the actual learning happens.
- If you get stuck for more than 15–20 minutes on one, write out the problem in your own
  words and break it into smaller steps — that alone often reveals the approach.
