# Day 016 — Loop Basics

Matches Tutorial Day 16 (The `if` Statement) — practice starts loops here, ahead of
Tutorial Day 19's deep dive. No limit on how many you solve.

## Basic

1. Print numbers from 1 to 100 using a `for` loop.
2. Print all even numbers from 1 to 50.
3. Print all odd numbers from 1 to 50.
4. Calculate the sum of numbers from 1 to 100 using a loop.
5. Print the multiplication table of 7 (7 x 1 to 7 x 10).
6. Print numbers from 100 down to 1 (counting backwards).
7. Print every 5th number from 0 to 100.
8. Count how many numbers between 1 and 100 are divisible by both 3 and 5.
9. Print the squares of numbers from 1 to 10.
10. Calculate the factorial of a number using a `for` loop.

## Concept

11. Print the multiplication tables for numbers 1 through 5 (nested idea, but simple loop-per-table is fine for now).
12. Sum only the even numbers from 1 to 100.
13. Find the largest number in a list using a loop (no `Math.max` yet).
14. Count how many vowels are in a fixed string using a loop over its characters.
15. Print a countdown from 10 to 1, then print "Liftoff!" after the loop ends.

## Interview-style questions

16. What are the three parts of a `for` loop's parentheses, and what does each one do?
17. What happens if you forget to update the loop's counter variable?
18. When would an infinite loop happen accidentally, and how would you notice it?

## Notes

- Always double check your loop's stopping condition before running it — an infinite
  loop will freeze your console/browser tab.
- Try solving a couple of these using `while` too (even before Day 17's tutorial) just
  to compare how the same problem looks in both loop styles.
