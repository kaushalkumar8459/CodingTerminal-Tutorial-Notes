1. How would you use it in JobHub?

## JobHub Scenarios
Observable execution, emissions, subscription, completion, errors, cold observables, and lazy execution. JobHub scenarios: understand HttpClient streams and user-event streams. Coding: create and subscribe to a typed Observable. Debugging: explain why code inside an Observable did not execute.

## Interviewer Follow-Ups
- How would this behave in a large Angular application?
- What performance or maintainability concerns exist?
- How would you debug a production issue involving this concept?
- What simpler alternative could work?

## Coding Question
Implement a small JobHub example based on this day's topic using strict TypeScript. Prefer modern Angular APIs and avoid `any`.

## Debugging Scenario
A developer's implementation works for the happy path but introduces a type, lifecycle, subscription, or architecture problem related to this topic. Explain how you would reproduce, diagnose, and fix it.

## Common Interview Traps
- Using `any` or unsafe casts to hide the real problem.
- Confusing compile-time types with runtime behavior.
- Adding abstractions without a real need.
- Ignoring lifecycle, cleanup, or error handling where applicable.
