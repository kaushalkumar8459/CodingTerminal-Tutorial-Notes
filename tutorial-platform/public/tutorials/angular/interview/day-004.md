# Day 4 — Standalone Components: Interview Questions

## Topic

**component anatomy, selector, template, styles, standalone components, component generation**

## Interview Goal

Create a standalone component and understand its role as a UI building block.

---

## Interview Questions

### Q1. What is an Angular component?

**Expected Answer:**
A component is a core UI building block that combines a template, component logic and styling.

### Q2. What is a standalone component?

**Expected Answer:**
A standalone component can be used without being declared in an NgModule and can declare its own component-level imports.

### Q3. What is a component selector?

**Expected Answer:**
It defines the custom HTML element or selector used to place the component in a template.

### Q4. What are the main parts of a component?

**Expected Answer:**
Typically metadata, a class containing component logic, a template, and styles.

### Q5. Why are standalone components important in modern Angular?

**Expected Answer:**
They simplify application composition and remove the need for NgModule declarations for ordinary components.

### Q6. How do you generate a component with Angular CLI?

**Expected Answer:**
Use an Angular CLI generate command such as `ng generate component name`.

### Q7. Can a component have its own styles?

**Expected Answer:**
Yes. Component styles can be provided directly or through a referenced stylesheet.

### Q8. Scenario: A generated component does not render. What would you check?

**Expected Answer:**
Check that the component is imported where needed, its selector is used correctly, and there are no template or compilation errors.

### Q9. Practical: Create HeaderComponent and ProfileComponent and render both from the application UI.

**Expected Answer:**
The learner should generate standalone components, use their selectors correctly, and explain the component boundary.
