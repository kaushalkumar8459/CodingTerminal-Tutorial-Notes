# Day 10 — Property Binding: Interview Questions

## Topic

**property binding, DOM properties, component properties, boolean properties**

## Interview Goal

Bind component state to DOM properties and understand property vs attribute binding.

---

## Interview Questions

### Q1. What is property binding?

**Expected Answer:**
Property binding sets a DOM element or component property from an Angular template expression.

### Q2. What is the syntax for property binding?

**Expected Answer:**
Square brackets are used, for example `[disabled]="isDisabled"`.

### Q3. Property binding vs interpolation — when would you use each?

**Expected Answer:**
Use interpolation mainly for text; use property binding when assigning DOM/component properties.

### Q4. What is the difference between an HTML attribute and a DOM property?

**Expected Answer:**
An attribute is part of the element's markup/initial configuration, while a DOM property represents the live object property exposed by the browser.

### Q5. Why does `[disabled]="isDisabled"` work differently from `disabled="isDisabled"`?

**Expected Answer:**
Property binding evaluates the expression; a plain attribute value is treated as attribute text rather than an Angular property expression.

### Q6. Can property binding target a component?

**Expected Answer:**
Yes. Property binding can provide values to component inputs, including modern signal inputs.

### Q7. Scenario: An image URL changes in component state. How should the image source be updated?

**Expected Answer:**
Use property binding such as `[src]="imageUrl"`.

### Q8. Practical: Create a profile UI with a bound image source, disabled button state and dynamic input value.

**Expected Answer:**
The learner should explain why each target is a property binding rather than plain text interpolation.
