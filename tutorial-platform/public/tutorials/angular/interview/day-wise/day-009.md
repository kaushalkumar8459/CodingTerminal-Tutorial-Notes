# Day 9 — Interpolation Deep Dive: Interview Questions

## Topic

**interpolation, expressions, displaying component data, expression limitations**

## Interview Goal

Display dynamic values correctly and understand when interpolation is appropriate.

---

## Interview Questions

### Q1. What is interpolation in Angular?

**Expected Answer:**
Interpolation uses `{{ expression }}` to evaluate a value and render it as text in a template.

### Q2. Can interpolation display component properties?

**Expected Answer:**
Yes. It is commonly used to display component state as text.

### Q3. Can interpolation call a method?

**Expected Answer:**
Template expressions can invoke methods, but methods used during rendering should be simple and side-effect free.

### Q4. What is the difference between interpolation and property binding?

**Expected Answer:**
Interpolation is primarily used to produce text, while property binding assigns a value to a DOM or component property.

### Q5. Can interpolation be used for boolean DOM properties such as disabled?

**Expected Answer:**
Property binding is the appropriate mechanism for DOM properties such as `[disabled]`.

### Q6. What is optional chaining useful for in templates?

**Expected Answer:**
It allows safe access when an intermediate value may be null or undefined.

### Q7. Scenario: `{{ user.name }}` throws because `user` can initially be unavailable. What can you use?

**Expected Answer:**
Optional chaining such as `{{ user?.name }}` can safely handle a missing intermediate value.

### Q8. Practical: Display a profile's name, role, email and optional company name using interpolation.

**Expected Answer:**
The learner should explain which values are text output and why interpolation is suitable.
