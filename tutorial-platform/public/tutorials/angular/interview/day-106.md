# Day 106 — HttpClient and provideHttpClient

## Interview Goal
Understand Angular's modern HTTP setup and how `HttpClient` fits into dependency injection.

## Level 1 — Basic Questions
1. What is Angular `HttpClient)?
2. How is `HttpClient` provided in a standalone Angular application?
3. What does `provideHttpClient()` do?
4. Why is dependency injection useful for HTTP services?
5. Where should `HttpClient` usually be injected?

## Level 2 — Understanding
1. Compare injecting `HttpClient` into a component versus a data-access service.
2. What is the role of `inject(HttpClient)`?
3. Why should HTTP services return typed results?
4. What does an `Observable` returned by `HttpClient` represent?
5. Why should URL configuration not be hard-coded throughout the application?

## Level 3 — Practical
1. Configure `provideHttpClient()` in a standalone application.
2. Create a `JobApiService` using `inject(HttpClient)`.
3. Add typed GET and POST methods.
4. Keep API URLs in configuration.
5. Expose feature-relevant methods from the data-access service.

## Level 4 — JobHub Scenarios
1. JobApiService is injected directly into five components. What boundary would you introduce?
2. Local and production environments use different API URLs. How should configuration work?
3. A service returns `Observable<unknown>`. How would you improve the contract?
4. A component subscribes to the same API method in several places. What design questions should you ask?

## Level 5 — Interviewer Follow-Ups
- Why does Angular's HttpClient use Observables?
- What does `provideHttpClient()` configure?
- How do interceptors fit into HttpClient?
- How would you test a service using HttpClient?

## Coding Question
Implement a typed `JobApiService` with `getJobs()` and `createJob()` using `inject(HttpClient)`.

## Debugging Scenario
`NullInjectorError` occurs for `HttpClient`. Identify the missing standalone provider configuration.

## Common Interview Traps
- Using old NgModule-only HTTP setup without understanding standalone configuration.
- Using `any` for API responses.
- Hard-coding environment-specific URLs.
- Putting HTTP calls directly in templates/components.

## Project Connection — JobHub
JobApiService becomes the data-access boundary used by candidate and recruiter features.

## Quick Revision
Standalone Angular applications configure HTTP through `provideHttpClient()), then consume it through injected typed services.

## Interview Readiness
You are ready when you can explain both the configuration and architectural role of HttpClient.
