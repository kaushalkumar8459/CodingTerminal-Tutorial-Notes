# Day 49 Interview Questions — Mini Project — Smart Product Catalog

## Interview Goal
Explain **Mini Project — Smart Product Catalog**, implement the relevant Angular pattern, discuss trade-offs, and apply it to a realistic JobHub scenario.

## Interview Questions

### 1. What directives are required in this mini project, and what does each own?
**Expected Answer:** A status directive that changes host presentation based on product status, and a highlight directive that provides reusable visual emphasis.

### 2. What pipes are required in this mini project, and what does each own?
**Expected Answer:** A price display/price-range pipe, a product status label pipe, and a relative-date or similar display transformation pipe.

### 3. Why must `@if`/`@for`/`@empty`/`track` be used instead of `*ngIf`/`*ngFor` in this project?
**Expected Answer:** The project follows modern Angular control-flow syntax as the primary approach for new code, reserving `*ngIf`/`*ngFor` for legacy maintenance scenarios.

### 4. Why should no directive make API calls in this project?
**Expected Answer:** Directives are meant to own reusable host behavior, not application data access; mixing in API calls breaks that boundary.

### 5. Why should no pipe mutate business state?
**Expected Answer:** Pipes are presentation transformations; mutating state inside a pipe creates unpredictable side effects tied to change detection.

### 6. How do components, directives, and pipes divide responsibility in this catalog?
**Expected Answer:** Components own UI structure (list, card, details, search), directives own reusable host behavior (status, highlight), and pipes own display transformation (price, label, date).

### 7. What would indicate that a directive or pipe has taken on too much responsibility?
**Expected Answer:** It performs API calls, mutates shared/business state, or depends on a single page instead of staying reusable and focused.

### 8. JobHub scenario: applying the same design rules to JobHub's job catalog, how would you structure job status and price/date formatting?
**Expected Answer:** Use a status directive to reflect job state on the host element and pipes to format salary and posted date, keeping components focused on structure and data flow.

## Interviewer Follow-Ups
- Why did you choose this approach?
- What alternative Angular approach could solve the same problem?
- What happens when the data changes?
- How would you test this behavior?
- What would you change for a large enterprise application?

Do not memorize syntax alone. Explain why the pattern fits the problem and which layer owns the responsibility.
