# Day 2 — Angular CLI and First Project: Interview Questions

## Topic

**Angular CLI, ng new, ng serve, project creation and build**

## Interview Goal

Create and run an Angular application; explain the role of CLI commands.

---

## Interview Questions

### Q1. What is Angular CLI?

**Expected Answer:**
Angular CLI is the command-line tool used to create, develop, test, build and maintain Angular applications.

### Q2. What does `ng new` do?

**Expected Answer:**
It creates a new Angular workspace and application with the selected project configuration.

### Q3. What does `ng serve` do?

**Expected Answer:**
It starts a local development server and rebuilds the application as source files change.

### Q4. What does `ng build` do?

**Expected Answer:**
It compiles and bundles the application for a build output suitable for deployment.

### Q5. Why should developers use Angular CLI instead of creating every file manually?

**Expected Answer:**
CLI provides consistent project scaffolding, generators, build tooling and development workflows.

### Q6. What is an Angular workspace?

**Expected Answer:**
A workspace is the development environment containing Angular project configuration and one or more projects.

### Q7. What is the difference between development and production builds?

**Expected Answer:**
A production build applies production-oriented compilation and optimization intended for deployment.

### Q8. Scenario: `ng serve` fails after creating a project. What would you check first?

**Expected Answer:**
Check the terminal error, Node/Angular CLI compatibility, dependencies, installation state and the command being run.

### Q9. Practical: Create a new Angular application and explain each command you run.

**Expected Answer:**
The learner should create the project, start it locally, make a small change, then produce a build and explain the purpose of each command.

## Interviewer Follow-Ups

Be prepared to answer these without memorizing definitions:

- Why is this concept needed at this point in an Angular application?
- What problem does it solve?
- How would you use it in a real project?
- What common mistake can a beginner make with it?
- How would you debug a problem involving this concept?

## Scenario Practice

**JobHub scenario:** Apply today's concept to the JobHub application. Explain the problem first, then identify the Angular feature that solves it. Do not introduce later concepts unless the scenario genuinely requires them.

## Common Interview Trap

Do not answer only with a definition. Follow the pattern:

```text
Definition → Why → Example → Project usage → Trade-off / limitation
```
