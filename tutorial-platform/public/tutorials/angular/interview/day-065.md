# Day 65 Interview Questions — Provider Recipes

## Interview Goal
Understand Angular value, class, factory, existing, and multi-provider patterns.

## Interview Questions

### 1. What is a value provider?
**Expected Answer:** It supplies a predefined value for a DI token.

### 2. What is a class provider?
**Expected Answer:** It maps a token to a class implementation.

### 3. What is a factory provider?
**Expected Answer:** It creates a dependency using a factory function, potentially using other injected dependencies.

### 4. What is an existing provider?
**Expected Answer:** It aliases another registered dependency so multiple tokens can resolve to the same instance.

### 5. What is a multi provider?
**Expected Answer:** It allows multiple values or implementations to be registered under one token and resolved as a collection.

### 6. What should provider factories avoid?
**Expected Answer:** Hidden global state, unnecessary side effects, and complex business workflows.

### 7. JobHub scenario
**Expected Answer:** A factory provider can select an API implementation based on injected deployment configuration.

## Interviewer Follow-Ups
- When would you choose a factory over a class provider?
- How does aliasing affect instance sharing?
- How do standalone applications configure providers?
- How would you test a provider factory?

## Common Interview Trap
Provider configuration is part of architecture. Do not put business logic into provider factories just because they can execute code.
