# Day 104 — Mini Project: Job Application Form

## Interview Goal
Apply Angular Forms concepts to a realistic job application workflow.

## Level 1 — Basic Questions
1. What controls are needed for a job application form?
2. Which fields should be required?
3. Which validations belong on the client?
4. Which rules must also be enforced by the backend?
5. How should submission state be represented?

## Level 2 — Understanding
1. Why should resume validation not rely only on file extension?
2. How would you model optional versus required application fields?
3. How should draft and submitted states differ?
4. How would you prevent duplicate applications?
5. How would you represent API errors in the form?

## Level 3 — Practical
1. Build a typed application form.
2. Add experience, notice period, salary expectation, and resume fields.
3. Add a custom control using CVA.
4. Add cross-field validation.
5. Add loading, success, failure, and retry states.

## Level 4 — JobHub Scenarios
1. A candidate applies twice because of a network retry. How should UI and backend cooperate?
2. Resume upload succeeds but application submission fails. How should the UI recover?
3. Backend returns a validation error for a field the client considers valid. How should the form handle it?
4. The form must support save-as-draft. What additional state is required?

## Level 5 — Interviewer Follow-Ups
- Why is backend validation still required?
- How would you test the complete submission flow?
- How would you separate file upload from application submission?
- What would you log when submission fails?

## Coding Question
Implement the application form with strict typing, validation, submission state, and API error handling.

## Debugging Scenario
The form becomes permanently disabled after a failed submission. Identify the missing state transition.

## Common Interview Traps
- Assuming HTTP 200 means business success.
- Trusting client validation as security.
- Combining file upload and application submission into one untestable component.
- Forgetting retry and recovery UX.

## Project Connection — JobHub
This is the final Forms module exercise and becomes the basis for later HTTP integration.

## Quick Revision
A production form is a stateful workflow, not just a collection of inputs.

## Interview Readiness
You are ready when you can explain the complete lifecycle from user input to validated submission and recovery.
