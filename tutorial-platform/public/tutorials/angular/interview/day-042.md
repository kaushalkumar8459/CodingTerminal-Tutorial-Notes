# Day 42 Interview Questions — Attribute Directives

## Interview Goal
Explain **Attribute Directives**, implement the relevant Angular pattern, discuss trade-offs, and apply it to a realistic JobHub scenario.

## Interview Questions

### 1. What is an attribute directive?
**Expected Answer:** A directive that changes the appearance or behavior of an existing host element without creating a new component.

### 2. Name two Angular built-in attribute directives.
**Expected Answer:** NgClass and NgStyle.

### 3. How does an attribute directive attach to a host element without replacing it?
**Expected Answer:** It uses an attribute-style selector, such as `[appHighlight]`, so the host element (for example a button) keeps its own tag and role.

### 4. Why does a directive typically use an attribute-style selector instead of an element selector?
**Expected Answer:** An attribute selector lets the directive attach to any existing element type and signals that it adds behavior rather than owning structure.

### 5. What is the difference between a directive and a component in terms of markup ownership?
**Expected Answer:** A component owns and renders its own template; a directive has no template of its own and only affects its host element.

### 6. How do you make a standalone directive available to a component?
**Expected Answer:** Import the standalone directive class into the component that uses it, the same way a standalone component is imported.

### 7. What is a common mistake when defining a directive's selector?
**Expected Answer:** Selecting elements too broadly, which can cause the directive to apply behavior in unintended places.

### 8. JobHub scenario: create a HighlightDirective that highlights featured job cards. What selector and metadata would you use?
**Expected Answer:** Use an attribute selector such as `[appHighlight]`, mark the directive standalone, and import it wherever a job card needs the highlight behavior.

## Interviewer Follow-Ups
- Why did you choose this approach?
- What alternative Angular approach could solve the same problem?
- What happens when the data changes?
- How would you test this behavior?
- What would you change for a large enterprise application?

## Common Interview Trap
Do not memorize syntax alone. Explain why the pattern fits the problem and which layer owns the responsibility.
