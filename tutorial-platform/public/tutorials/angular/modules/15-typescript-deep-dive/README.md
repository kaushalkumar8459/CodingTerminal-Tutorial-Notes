# Module 15 — TypeScript Deep Dive

## Goal
Strengthen TypeScript from practical fundamentals to advanced type-safe architecture for Angular applications.

## Why This Module Comes Now
Days 1–145 built complete Angular applications. TypeScript is now taught deeply so learners can model APIs, component contracts, forms, services, state, errors, and reusable libraries with confidence.

## Sequence
146. Why TypeScript Matters in Angular
147. Types, Arrays, Tuples and Objects
148. Type Inference and Variable Declarations
149. Interfaces and Type Aliases
150. Functions and Function Types
151. Union, Literal and Intersection Types
152. Narrowing and Type Guards
153. Generics Fundamentals
154. Generic Constraints and Defaults
155. Utility Types
156. keyof, typeof, Indexed Access and as const
157. Mapped Types
158. Conditional Types
159. Template Literal Types
160. Classes, Abstract Classes and Access Modifiers
161. Modules, Imports and Type-Only Imports
162. unknown, never and Exhaustive Error Handling
163. TypeScript with Angular API Models and Forms
164. Type-Safe Architecture Patterns
165. Mini Project — Type-Safe Job Platform Domain

## Learning Rules
- Prefer strict typing and meaningful domain types.
- Prefer `unknown` over `any` at unsafe boundaries.
- Prefer literal unions for many application state values.
- Use generics when one abstraction genuinely works across multiple types.
- Understand runtime JavaScript separately from compile-time TypeScript.
- Do not introduce RxJS or external state libraries here; those are later phases.

## Outcome
By Day 165, learners should be able to design type-safe Angular domain models, API contracts, form models, reusable generic utilities, and exhaustive UI state handling.
