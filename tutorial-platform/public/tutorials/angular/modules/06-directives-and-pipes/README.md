## Dependency rule

The learner already knows templates, built-in control flow, component communication, and reusable component boundaries. This module introduces directives when reusable DOM behavior is needed and pipes when reusable display transformation is needed.

Modern built-in control flow such as @if and @for remains the primary rendering approach. Legacy structural directives such as *ngIf and *ngFor are covered for maintenance/interview awareness, not as the preferred new-code pattern.

## Outcome

Create reusable DOM behavior with attribute directives, understand host bindings/listeners, transform display values with built-in and custom pipes, and choose between components, directives, and pipes.
