# Module 22 — Security

## Days 246–254

Learn Angular security from the browser boundary through HTTP, authentication, CSP, Trusted Types, dependency hygiene, and production review.

### Sequence

- Day 246 — Angular Security Model and Threat Thinking
- Day 247 — XSS, Sanitization and Security Contexts
- Day 248 — DomSanitizer and Safe Dynamic Content
- Day 249 — CSP, Trusted Types and AOT
- Day 250 — CSRF/XSRF, XSSI and Secure HTTP
- Day 251 — Authentication, Authorization and Secure Session Design
- Day 252 — Browser Storage, Cookies and Sensitive Data
- Day 253 — Dependency, Supply-Chain and Production Security
- Day 254 — Mini Project — Security-Hardened JobHub

Angular treats template-bound values as untrusted by default and sanitizes/escapes values in relevant DOM contexts. CSP and Trusted Types provide additional browser-level protection.
