## Dependency rule

The learner now understands component communication, directives, pipes, and routing. This module moves from individual reusable components to composing them into larger UI structures.

Services, HTTP, RxJS, and global state are intentionally deferred until they are needed.

## Outcome

Build reusable UI primitives, compose them into feature-level structures, use content projection and dynamic component rendering appropriately, and establish clean component contracts.
