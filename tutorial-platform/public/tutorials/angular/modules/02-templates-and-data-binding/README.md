# Module 2: Templates and Data Binding

## Purpose

After learning components, the learner needs to answer a practical question:

**How does component data appear in the UI, and how does the UI respond to user actions?**

This module introduces Angular template syntax and data binding before control flow, services, HTTP, RxJS, or state-management libraries.

## Dependency Flow

```text
Component
  ↓
Template
  ↓
Interpolation
  ↓
Property binding
  ↓
Attribute/class/style binding
  ↓
Event binding
  ↓
Two-way binding
  ↓
Template best practices
  ↓
Interactive UI project
```

## Learning Rule

Do not introduce loops, conditions, routing, services, HTTP, RxJS, or external state libraries yet. Each will be introduced when the application has a reason to need it.

## Module Project

Build an **Interactive Profile UI** that displays profile data, reacts to user actions, supports simple editing, and demonstrates one-way and two-way binding.

## Completion Criteria

The learner should be able to explain and implement interpolation, property binding, attribute/class/style binding, event binding, two-way binding, and clean template/component responsibility separation.
