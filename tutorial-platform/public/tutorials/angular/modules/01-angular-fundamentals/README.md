# Module 01 — Angular Fundamentals

**Days:** 1–7  
**Level:** Beginner

## Goal

Build the mental and practical foundation required to start developing modern Angular applications.

## Learning Sequence

| Day | Topic | Practical Reason |
|---|---|---|
| 1 | What is Angular and Why Angular? | Understand why a framework is useful |
| 2 | Angular CLI and First Project | We now have a reason to create an application |
| 3 | Angular Project Structure | The generated project needs to be understood |
| 4 | Standalone Components | We need to understand the UI building block |
| 5 | Component Template and Styles | Components need visible UI |
| 6 | Angular Application Flow | Connect bootstrap, components, templates, and browser |
| 7 | First Mini Project | Combine the fundamentals |

## Dependency Rule

    Why Angular?
        ↓
    Create application
        ↓
    Understand structure
        ↓
    Understand components
        ↓
    Build component UI
        ↓
    Understand application flow
        ↓
    Build mini project

Every day prepares the learner for the next day.

## Module Project

Build a **Personal Profile App** progressively using:

- Angular application creation
- Standalone components
- Templates
- Component styles
- Basic application structure
- Component composition

Do not introduce routing, services, HTTP, RxJS, state management, authentication, or advanced architecture before they are needed.

## Completion Criteria

By the end of Day 7, the learner should be able to:

- Explain Angular.
- Create and run an Angular application.
- Explain important generated project files.
- Understand standalone components.
- Create and compose components.
- Build component templates and styles.
- Explain the high-level Angular application flow.
- Build and successfully compile a small Angular application.
- Explain why each concept was introduced when it was.
