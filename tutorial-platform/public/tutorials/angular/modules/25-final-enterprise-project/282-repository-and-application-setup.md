# Day 282 — Repository and Application Setup

Set up the repositories, Angular applications, environments, package conventions and development workflow for the capstone.

## Goal
Create a repeatable foundation for the host and Candidate, Recruiter and Admin applications.

## Setup Areas
- Angular standalone projects
- TypeScript strictness
- routing and application configuration
- lint/format conventions
- environment and runtime configuration boundaries
- local development commands
- test setup with Vitest
- source-control and commit conventions

## Exercise
Create a minimal host and one feature application. Verify local builds, tests and navigation before adding business functionality.

## Common Mistakes
Copying production configuration into source control; adding dependencies before defining ownership; skipping a clean baseline build and test run.

## Interview Questions
1. What should be established before feature development begins?
2. Which configuration belongs at build time versus runtime?
3. Why is a reproducible development setup important?

## Outcome
The capstone has a clean, repeatable application foundation.
