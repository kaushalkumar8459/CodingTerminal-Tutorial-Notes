## Dependency rule

The learner already has multiple routed screens and reusable UI pieces. This module introduces communication only when components need to exchange data and events.

The modern Angular APIs input(), output(), model(), viewChild(), viewChildren(), and content projection are primary. Legacy @Input, @Output, ViewChild, and EventEmitter are covered later for maintenance and interview awareness.

## Outcome

Build reusable components with clear input/output contracts, two-way bindings, projected content, and view queries without introducing global state prematurely.
