# Angular Modules

This directory contains the complete Angular learning modules.

Each module should contain a README and a `days/` directory.

Example:

```
01-angular-fundamentals/
├── README.md
└── days/
    ├── day-001-what-is-angular.md
    ├── day-002-installation-and-cli.md
    └── ...
```

The modules follow the dependency order defined in ../roadmap.md.
