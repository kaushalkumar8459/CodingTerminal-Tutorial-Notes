# Module 18 — CDK, Material & Accessibility

**Days 201–212**

This module teaches Angular CDK behavior primitives, Angular Material, responsive UI utilities, overlays, dynamic content, drag and drop, accessibility tooling, and Angular Aria.

## Learning Principles

- Prefer native semantic HTML before custom widgets.
- Use CDK when behavior is needed without adopting a visual design system.
- Use Angular Material when ready-made accessible UI components accelerate delivery.
- Treat accessibility as part of component design.
- Prefer standalone imports and modern Angular control flow.
- Keep state and behavior typed; avoid any.
- Use signals for local UI state where appropriate.
- Verify keyboard, focus, screen-reader semantics, responsive behavior, and reduced-motion expectations.

## Prerequisites

Days 1–200, especially components, routing, forms, HTTP, TypeScript, RxJS, signals, and state management.
