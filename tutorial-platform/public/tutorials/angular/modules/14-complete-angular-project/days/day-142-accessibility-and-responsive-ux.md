# Day 142 — Accessibility and Responsive UX

## Goal
Make JobHub usable across devices and by people using assistive technologies.

## Accessibility Checklist
- semantic HTML
- associated labels
- keyboard navigation
- visible focus
- meaningful button names
- accessible form errors
- sufficient contrast
- logical heading hierarchy
- dialog focus management
- status/error announcements where appropriate

## Responsive Checklist
- mobile navigation
- responsive job cards
- readable forms
- touch-friendly controls
- responsive tables/admin views

## Exercise
Navigate the main workflows using only the keyboard and test common mobile widths.

## Common Mistakes
- Using div elements as buttons.
- Relying only on color to communicate status.
- Removing focus outlines without replacement.
- Testing only desktop.

## Interview Questions
1. Why is semantic HTML important?
2. How do you make forms accessible?
3. What is keyboard accessibility?

## Outcome
You can review Angular UI beyond functional correctness.
