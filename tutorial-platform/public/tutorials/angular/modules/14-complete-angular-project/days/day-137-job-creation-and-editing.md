# Day 137 — Job Creation and Editing

## Goal
Apply the forms module to a real business workflow.

## Form Sections
- title
- company
- description
- location
- work mode
- employment type
- salary
- skills
- application deadline

## Requirements
- typed reactive form
- validation
- custom validation where needed
- edit mode
- submission state
- server-error display
- accessible labels and errors

## Permission
Only users with the appropriate job-management permission should access creation/editing.

## Exercise
Build create and edit pages using one reusable form model.

## Common Mistakes
- Duplicating create and edit forms.
- Disabling submit without explaining validation errors.
- Treating server validation as identical to client validation.

## Interview Questions
1. How do you reuse a form for create and edit?
2. Client vs server validation?
3. How should API validation errors appear?

## Outcome
You can connect complex Angular forms to real API mutations.
