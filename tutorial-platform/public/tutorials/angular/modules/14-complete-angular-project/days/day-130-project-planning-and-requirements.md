# Day 130 — Project Planning and Requirements

## Goal
Turn the skills from Days 1–129 into a complete application plan.

## Project
Build **JobHub**, an authenticated job management platform.

## User Types
- Candidate
- Recruiter
- Admin

## Candidate Features
- browse jobs
- search and filter
- view job details
- save jobs
- manage profile
- track applications

## Recruiter Features
- create jobs
- edit jobs
- close jobs
- review applications

## Admin Features
- manage users
- manage permissions
- review platform data

## Planning Exercise
Create:
1. feature list
2. route map
3. permission matrix
4. API contract list
5. component hierarchy
6. acceptance criteria

## Common Mistakes
- Starting with components before defining user journeys.
- Building every feature at once.
- Adding technology before identifying the problem it solves.

## Interview Questions
1. How do you break down a large Angular feature?
2. What should be decided before implementation?
3. How do requirements affect component boundaries?

## Outcome
You can convert requirements into an Angular implementation plan.
