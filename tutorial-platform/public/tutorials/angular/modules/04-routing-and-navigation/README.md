# Module 4 — Routing & Navigation

## Days 23–31

1. Day 23 — Why Routing? SPA Navigation Problem
2. Day 24 — Route Configuration and provideRouter
3. Day 25 — RouterLink, RouterLinkActive, and Programmatic Navigation
4. Day 26 — Route Parameters
5. Day 27 — Query Parameters and Navigation State
6. Day 28 — Nested Routes and Layouts
7. Day 29 — Route Guards
8. Day 30 — Lazy Loading and Route-Level Code Splitting
9. Day 31 — Mini Project: Multi-Page Job Portal

Routing is introduced now because learners already understand components, templates, data binding, control flow, lists, and UI states. Authentication, HTTP, RxJS, and advanced state management are intentionally deferred.

Examples use standalone components, provideRouter, modern control flow, signals where useful, and inject(). Legacy routing patterns are mentioned later for maintenance/interview awareness.

## Outcome

Build a multi-page Angular SPA with navigation, route parameters, query parameters, nested layouts, guards, and lazy-loaded routes.
